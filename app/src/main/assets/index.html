Communiquer avec J.A.R.V.I.S. · Jarvis local uniquement

Jarvis répond entièrement sur le téléphone sans Mistral. Écris une question et appuie sur Envoyer : la réponse sera affichée et prononcée en français, même si le micro est arrêté. Pour parler, active l’écoute Vosk et dis « Friday… » ou « Jarvis… ». Le premier démarrage et le bouton « Interrompre la réponse et écouter » ouvrent aussi 15 secondes de dictée sans mot-clé. Un modèle IA local compatible doit être importé dans Réglages. En activant Internet Jarvis, les recherches consultent des sources publiques HTTPS et affichent leurs liens ; seul le modèle sur le téléphone génère la réponse. Les mots-clés de recherche sont transmis aux services Web consultés, jamais l'historique privé.

Journal d'anomalies · sauvegarde locale

Les événements techniques sont enregistrés automatiquement pendant 14 jours maximum, dans un journal chiffré sur ce téléphone : microphone, Vosk, réponses, RSS/Web, LiteRT, GPS et durées. Les paroles, conversations, URL, mots de passe, profils et coordonnées GPS ne sont jamais ajoutés aux logs. Aucune synchronisation automatique.

Pour aider à améliorer JARVIS, « Signaler sur GitHub » prépare un brouillon public avec les seuls codes de diagnostic et durées relatives, sans conversations ni données privées. L'utilisateur doit approuver l'ouverture et publier lui-même sur GitHub ; le contenu du brouillon est transmis à GitHub dès l'ouverture du navigateur. Le rapport JSON complet avec conversation reste strictement local jusqu'à un export manuel : ne le publiez pas sur GitHub.

Au moment de sauvegarder un JSON local, cochez « Inclure la conversation : questions et réponses » pour relier les échanges aux événements techniques. Par défaut, l'export ne contient que les codes. Le JSON n'est pas chiffré et peut exposer des informations personnelles : relisez-le avant tout partage. Aucun envoi automatique.
